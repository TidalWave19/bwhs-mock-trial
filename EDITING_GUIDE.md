# Quick Editing Guide

## Change names, roster, officers, meeting time, email, form, Schoology code, or homepage numbers

Edit **`club-data.js`**. It is the main easy-edit file.

Examples:

```js
email: "new-email@example.com",
meeting: "Tuesdays · 4:18–5:30 PM",
schoologyCode: "NEW-CODE",
```

For the roster, edit the `roster` list. For officers, edit the `officers` list.

## Change the schedule
When dates are confirmed, edit **`schedule.html`** and replace the current “Schedule being finalized” card with the official events.

## Change resources
Edit **`resources.html`**. Add official Google Drive/Docs links only after they are ready to be shared.

## Change the visual design
Edit **`styles.css`**.

## Publishing changes
You do NOT need to create another GitHub Pages site. Commit your changes to the `main` branch of the existing repository. GitHub Pages will automatically redeploy the site.
