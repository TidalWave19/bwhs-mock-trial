# BWHS Mock Trial Club — GitHub Pages Site

This is the 2026–2027 website for BWHS Mock Trial Club at Briar Woods High School.

## Easy editing
Most club information is centralized in **`club-data.js`**. You can edit the club name, season, meeting time, contact email, Schoology code, officers, roster, and homepage statistics there.

### Updating the site on GitHub
1. Open the repository: `TidalWave19/bwhs-mock-trial`.
2. Open `club-data.js`.
3. Click the pencil **Edit** icon.
4. Change the information between the quotation marks / numbers.
5. Click **Commit changes**.
6. GitHub Pages will automatically rebuild the site.

For larger design/content changes, edit the appropriate HTML file or `styles.css`.
