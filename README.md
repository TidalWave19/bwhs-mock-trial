# BWHS Mock Trial Club — Static Website

This is a GitHub Pages / Netlify / Vercel-ready static site designed to closely mimic the screenshots supplied in the conversation.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload every file in this folder to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → main → /(root).
5. Save. GitHub will give you a public URL.

## Customize
- Replace placeholder officer/team information with club-approved information.
- Replace the application URL in join.html with the club's Google Form.
- Replace resource `#` links with official Google Drive/Docs links.
- Replace the placeholder club email.
- Update schedule dates before publishing.

No backend is required.
